## tfclinical
R package of vignettes for learning how to use Tensorflow in RStudio, for drug development and clinical research use cases. Multi-lingual Rmarkdown is used - mixture of R and Python.
 
This is the repo. Contributions welcome! 

See [here](https://fraseriainlewis.github.io/tfclinical/) for pkgdown website.
